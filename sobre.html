Sobre Mim

Olá! Sou o Wiliam, professor de matemática e apaixonado por tecnologia. Criei o projeto Dicas para o Encceja para ajudar alunos que, como muitos que já ensinei, têm dificuldade em matemática básica.

Estou em transição para desenvolvimento Front-end Jr, estudando código limpo, boas práticas (SOLID) e criação de produtos que realmente ajudam pessoas. Meu objetivo é entrar no mercado como dev júnior e continuar criando ferramentas educacionais gratuitas.

O que estou construindo

📚 Dicas para o Encceja: Plataforma com calculadora, estatística completa em Python e JavaScript, 100% responsiva. Paleta profissional branco/azul/preto.

💻 Stack: HTML semântico, CSS moderno, JavaScript puro, Python (Counter, statistics), GitHub Pages, matplotlib para gráficos.
