📚 Dicas Encceja 2026

> Plataforma gratuita criada para ajudar jovens e adultos que não concluíram os estudos a se prepararem para o Encceja.

🎯 Sobre o projeto
O site reúne aulas resumidas, dicas de redação nota 10 e simulados com gabarito das 4 áreas do conhecimento do Encceja:
- Linguagens e Códigos
- Ciências Humanas
- Ciências da Natureza
- Matemática

Projeto desenvolvido como parte da graduação em *Licenciatura em Matemática*.

🚀 Tecnologias
- HTML5
- CSS3
- JavaScript
- GitHub Pages

🎓 Objetivo Acadêmico
Democratizar o acesso à educação e aumentar a taxa de aprovação no exame.
